Garnet Privacy Proxy — Test Report

Date: 22 July 2026  |  Model: claude-opus-4-7  |  Image: privacy-proxy:016626682  |  All 8 scenarios passed

This report validates that the Garnet privacy proxy correctly protects personal data before sending messages to the AI model, and correctly restores real information in the response shown to the user.

S1 — Normal Prompt with PII  ✅ PASS

Privacy ON · No files · No web search

The user sends a message containing their name, company, and location. Garnet detects the personal data, replaces it with anonymous tokens before sending to the AI, and restores the real names in the response shown to the user.

4 personal data items detected and protected: name, company, and two locations.

S2 — Message with No Personal Data  ✅ PASS

Privacy ON · No files · No web search · New chat

The user sends a simple question with no personal data. Garnet correctly identifies that nothing needs to be protected and forwards the message directly to the AI without modification.

0 items detected. Message sent unchanged. No overhead from privacy processing.

S3 — Multi-turn Conversation  ✅ PASS

Privacy ON · Same chat · Two messages

The user sends a first message introducing themselves, then a follow-up question in the same chat. Garnet re-protects the full conversation history on every new message — including the AI's previous responses — before sending the full context to the AI.

History correctly re-pseudonymized on turn 2. All 3 messages in context protected.

S4 — Web Search  ✅ PASS

Privacy ON · Web search enabled

The user asks a question that triggers a web search. Garnet receives both the web search results and the user's message, and pseudonymizes personal data found in both — the webpage content and the user's own message — before sending everything to the AI.

9 items protected: 7 from web search results + 3 from user message (with overlap).

S5 — File Upload with Personal Data  ✅ PASS

Privacy ON · Employee record uploaded

The user uploads a document containing an employee record with name, email, phone, IBAN, company, and location. Garnet scans the file at upload time, detects all 6 types of personal data, and protects them whenever the file content is included in a conversation.

6 types of personal data detected in the file: PERSON, EMAIL, PHONE, IBAN, ORGANIZATION, LOCATION.

S6 — Multiple PII Types in One Message  ✅ PASS

Privacy ON · All entity types active

The user sends a message containing 6 different types of personal data at once: a name, email address, phone number, IBAN, company name, and city. Garnet correctly detects and protects all 6 types in a single pass.

6 different types of personal data detected and protected in one message.

S7 — Full Stack: File + Web Search + Multi-turn  ✅ PASS

Privacy ON · File uploaded · Web search enabled · Multi-turn

The most complex scenario: the user has uploaded a file, web search is active, and the conversation has multiple turns. Garnet protects personal data coming from three different sources simultaneously — the uploaded file, the live web search results, and the user's typed message.

13 items protected across all three sources: file, web results, and user message.

S8 — Privacy Mode OFF  ✅ PASS

Privacy disabled

When privacy is disabled, Garnet forwards all messages directly to the AI without any processing. This serves as a baseline to measure what the AI response time looks like without the privacy layer.

0 items processed. Message forwarded raw. Fastest response: 2.27s total.
