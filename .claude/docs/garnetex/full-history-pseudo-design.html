The Cache — why it matters

Without cache — spaCy calls per turn

Each turn re-scans ALL previous messages
Turn 1→1 spaCy call
Turn 2→3 spaCy calls (2 old + 1 new)
Turn 5→9 spaCy calls
Turn 10→19 spaCy calls
O(n²) — gets slower every turn ❌

With cache — spaCy calls per turn

Old messages: cache hit (free). New message: 1 spaCy call.
Turn 1→1 call
Turn 2→1 call 2 hits
Turn 5→1 call 8 hits
Turn 10→1 call 18 hits
O(1) — always 1 spaCy call per turn ✓

How the cache works

# Structure: session_id → { md5(text) → masked_text }
pseudo_cache: dict[str, dict[str, str]] = {}

def _pseudo_with_cache(text, session_id, enabled_types) -> str:
    h = hashlib.md5(text.encode()).hexdigest()     # fast fingerprint of text
    session_cache = pseudo_cache.setdefault(session_id, {})

    hit = session_cache.get(h)
    if hit is not None:
        return hit                                 # free — no spaCy

    out = pseudonymize(text, session_id, ...)       # spaCy runs here
    session_cache[h] = out
    return out

How Does the Cache Know It Already Saw a Message?

Every text gets a unique fingerprint (md5). Same text = same fingerprint. Cache stores fingerprint → result.

Step 1 — Fingerprinting

"Max works at Enclaive"
→ md5 →
a3f7c1b2
"what is his email?"
→ md5 →
d9e2f1a4
"Max works at Enclaive" (same text again)
→ md5 →
a3f7c1b2
Same text → always same fingerprint. That's how the cache recognises it.

Step 2 — The Cache Dictionary

pseudo_cache["session-abc123"] = {
"a3f7c1b2" → "PERSON_cc75010d works at ORGANIZATION_bd3a68a5"
"d9e2f1a4" → "what is his email?" (no PII)
"b8c2d5e1" → "EMAIL_ADDRESS_f3a12b99"
}
Cache HIT
Fingerprint found in dict → return saved result immediately. spaCy never runs.
Cache MISS
Fingerprint not found → run spaCy → save result in dict → return. Next time: HIT.

Step 3 — Turn by Turn Walkthrough

TURN 1 — You send "Max works at Enclaive"
OWU sends: [ {user: "Max works at Enclaive"} ] MISS
Proxy runs spaCy: "PERSON_cc75010d works at ORGANIZATION_bd3a68a5"
Cache saves: a3f7c1b2→"PERSON_cc75010d works at ORGANIZATION_bd3a68a5"
spaCy calls: 1
