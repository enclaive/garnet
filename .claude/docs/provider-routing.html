Privacy applies to ALL providers Pseudonymization and depseudonymization run in the proxy before any request is forwarded — regardless of which provider is selected.
Anthropic auth conversion Authorization: Bearer sk-ant-xxx is rewritten to x-api-key: sk-ant-xxx + anthropic-version: 2023-06-01 before forwarding.
Ollama — no streaming Ollama path uses a separate non-streaming handler. Response is received in full, depseudonymized, then returned. Streaming is intentionally disabled.
Web search — requires legacy FC For models where OWU defaults to native function calling (e.g. Mistral), set Function Calling → legacy in Admin → Models to enable OWU-injected web search.
Known minor gap — query expansion Query expansion variants (RAG only) are sent to OWU's embedding model unpseudonymized. They do not reach the main LLM. Only relevant when query expansion is enabled.
Session isolation Each chat_id gets its own mapping table. No cross-chat data leakage. Sessions expire after 1 hour of inactivity (Redis TTL).
