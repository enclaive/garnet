3 · Privacy Layer
Garnet Privacy Proxy — 15-step pipeline
Every chat request passes through all steps below in order
① Read body
await request.json() — full body into memory. POST/PUT only.
② Pop Garnet fields
privacy_proxy → privacy on/off
chat_id → session key
Both stripped — never reach LLM.
③ Extract messages + fix stream
Extract messages[], model, build session_id. OpenAI: keep stream. Ollama: force stream=False.
④ Build final URL
Read x-openai-base-url + append actual_path. Detect provider from auth header → convert Anthropic Bearer→x-api-key.
⑤ Classify last message
internal (title/tags) → skip all
system prompt marker → skip
has <source> → RAG path
else → plain user path
⑥ History scan
Loop all messages except last. Re-pseudonymize using current session mapping. Skip system prompts + OWU markers.
⑦ pseudonymize() — lang detect
langdetect → language code → load matching spaCy model (en/de/fr…)
⑧ Regex pass
Fast pattern scan: emails, IBANs, phones, IDs. No language needed. Runs before spaCy.
⑨ Strip markdown
Remove **bold**, `code`, _italic_ before NER. spaCy trained on plain text — markdown breaks entity detection.
⑩ spaCy NER
Language model reads cleaned text → returns spans: [(0,10,"PERSON"), (20,29,"ORG")]
⑪ Filter overlaps
Merge regex + spaCy spans. Overlapping → keep longest. Exact duplicate → keep one.
⑫a Generate token
PERSON_{SHA256(value)[:8]}
Deterministic — same value always same token. Store reverse: token → real in session.
⑫b Replace in text
Replace spans right-to-left (char positions). Earlier positions don't shift when later spans replaced first.
⑬ Rebuild content
Put pseudonymized text back into message structure. String → replace. Multipart (text+image) → replace text block only, keep image untouched.
⑭ Forward to LLM
httpx streams request to real provider. Only: authorization, content-type forwarded. All Garnet headers stripped.
⑮ LLM responds → depseudo (15a–15g)
15a Receive SSE stream chunk by chunk via httpx.aiter_lines()
15b Parse each chunk → extract delta.content text. Empty delta → forward as-is.
15c Scan delta for tokens. No token found → stream immediately.
15d Replace tokens longest-first → avoids prefix collision.
15e Buffer partial tokens split across chunks. Merge buffer + next chunk before scan.
15f Yield depseudonymized chunk as SSE via FastAPI StreamingResponse.
15g On [DONE]: flush buffer, write audit log (chunks, tokens restored, timing), close connections.
Browser sees real names. LLM never did. Session mapping stays in proxy.

OpenAI · Groq · Gemini · OpenRouter → streaming Anthropic → streaming (x-api-key header) Ollama → non-streaming (stream: false)
Privacy enforced how?
FORCE_OPENAI_BASE_URL env var in docker-compose / Helm overrides OWU's configured provider URL at runtime — all traffic is forced through the proxy regardless of admin settings.
Auth flow
Browser authenticates to OWU via JWT (session-based). OWU attaches the provider API key to every outbound request. Proxy forwards the key unchanged (except Anthropic header conversion).
Web search path
middleware.py runs DDGS search, injects results as a system message. Proxy receives the enriched body and pseudonymizes the search context too — LLM never sees real names from search results.
